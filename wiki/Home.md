# Horror Banshee — Wiki officiel

**Ne la fixe pas.**

Une femme seule entre les arbres. Un chant discret. Un regard de trop.
Horror Banshee ajoute à Minecraft une rencontre qui commence dans le calme et
se termine dans les pleurs, la frénésie et un cri.

![La Matriarche](../media/06-matriarch-revealed.webp)

Cette documentation décrit la **version 0.11.1** : Minecraft Java **1.21.1**,
**NeoForge 21.1.256** et **GeckoLib 4.9.3**, avec **Java 21**.
